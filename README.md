# CS4207 - NYC Taxi Trip Duration Prediction

## Introduction

Predict the trip duration (Estimated Time of Arrival) of NYC taxi trips using regression.

> Get started by following [`GUIDE.md`](GUIDE.md)

## Dataset

Public records of New York City yellow taxi trips

- Train on data from 2024-01 to 2025-12
- Test on data from 2026-01 to 2026-09

Source: [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)
